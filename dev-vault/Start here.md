# Start here

This is the Vikalp dev vault. Open **Essays/The cost of the obvious** and try:

- Select a word, press ⌘⇧A, type another version, press Return.
- Hover the word and press the arrow keys.
- Select a sentence, right-click, choose **Ghost it**.
- Select a paragraph, press ⌘⇧X to stash it in Overflow.
- Click the lint icon in the status bar to run the linter.
- Click **Lab** in the status bar for AI marks and trim.
